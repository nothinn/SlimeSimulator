================================================================================
  KEY FIXES APPLIED
================================================================================

1. VGA Address Mapping (Fixed 2x)
   Problem: Only first 7 lines showing content
   Root Cause: Memory writes limited to 1000 locations
   Solution: Iterate through all 19,200 locations each frame
   Result: ✅ Full screen display

2. Coordinate Transformation (Fixed)
   Problem: Pixels not mapping correctly to simulation space
   Root Cause: 4× upscaling not accounted for in address calc
   Solution: Implemented right-shift by 2: (pixel >> 2)
   Result: ✅ Correct pixel-to-memory mapping

3. Simulation Control (Documented)
   Problem: Display not updating after programming
   Root Cause: Simulation starts in IDLE, needs button press
   Solution: Documented requirement to press BTNC
   Result: ✅ Users now know to start simulation

================================================================================
  HOW TO DEMO
================================================================================

1. Connect VGA monitor to Basys3 J17 (VGA connector)
2. Power up Basys3 board
3. Press BTNC (center button) - simulation starts
4. Watch full-screen greenscale noise pattern
5. Press BTNU to speed up, BTND to slow down
6. Press BTNL to randomize with new LFSR seed
7. Watch LEDs show speed level (LED[3:0]) and state (LED[4])

Expected: Full-screen dynamic noise pattern in green tones
