                      QUICK START GUIDE
================================================================================

VERIFY FPGA IS PROGRAMMED:
  $ python3 scripts/fpga_programmer.py --check-only

OBSERVE HARDWARE BEHAVIOR:
  1. Power on Basys3 board
  2. Check LED indicators (should show speed level 0-15)
  3. Connect VGA monitor - should see animated patterns
  4. Press BTNC to start/stop simulation
  5. Press BTNU/BTND to adjust speed
  6. Press BTNL to randomize with new seed

RUN VALIDATION TESTS:
  $ python3 scripts/run_all_validations.py
  $ python3 scripts/fpga_validation.py --all --verbose

RUN INDIVIDUAL TESTS:
  $ python3 scripts/validate_lfsr.py --verbose
