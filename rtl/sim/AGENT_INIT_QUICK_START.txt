GENERATED DATA FORMAT
================================================================================

  const int32_t AGENT_INIT_DATA[][3] = {
      {x_fp, y_fp, angle_fp},  // Agent 0
      {x_fp, y_fp, angle_fp},  // Agent 1
      ...
  };

  Format: Q12.12 fixed-point (scale = 4096)

  Example (Agent 0 at 320×240):
    x_fp     = 0x00100000 = 1048576 = 256.00 pixels
    y_fp     = 0x00078000 =  491520 = 120.00 pixels
    angle_fp = 0x00003244 =   12868 = 3.1416 radians (180°)

================================================================================
CIRCLE SPAWN PARAMETERS
================================================================================

  Center: (WIDTH/2, HEIGHT/2)
  Radius: min(WIDTH, HEIGHT) × 0.40

  For 320×240:
    Center: (160, 120) pixels
    Radius: 96 pixels

  Agent positions:
    Evenly distributed around circle
    All pointing inward (toward center)
    Agent i at angle: 2π × i / NUM_AGENTS

  --width W         Width in pixels (default: 320)
