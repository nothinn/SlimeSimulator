ILA - INTEGRATED LOGIC ANALYZER
================================================================================

Configuration:
  - Sample Depth:     8,192 samples (8K cycles)
  - Clock Domain:     100 MHz (clk_100mhz)
  - Total Probe Width: ~100 bits
  - Memory Usage:     ~120 Kbits BRAM
  - Trigger:          Advanced, multi-condition

Common Trigger Conditions:
  - Frame boundary:       frame_start == 1
  - Agent processing:     sim_state == 4'b0010 (RUN_AGENTS)
  - Memory write:         trail_we_b == 1
  - Specific agent:       agent_idx == 10'd<N>
  - Button press:         btn_debounced[0] == 1 (center button)
  - LFSR sequence:        lfsr_state == 32'h<value>

TCL Commands:
  # Set trigger on frame start
  set_property TRIGGER_COMPARE_VALUE {eq1'b1} \\
    [get_hw_probes frame_start -of_objects [get_hw_ilas hw_ila_1]]

  # Arm and capture
  run_hw_ila hw_ila_1
  wait_on_hw_ila hw_ila_1

  # View waveform
  display_hw_ila_data [upload_hw_ila_data hw_ila_1]

  # Export to CSV
  write_hw_ila_data -csv_file capture.csv hw_ila_1

TCL Commands:
  # Read current LFSR state
  set lfsr [get_property INPUT_VALUE \\
    [get_hw_probes lfsr_state -of_objects [get_hw_vios hw_vio_1]]]
  puts "LFSR: 0x[format %08X $lfsr]"

  # Read frame count
  set frames [get_property INPUT_VALUE \\
    [get_hw_probes frame_count -of_objects [get_hw_vios hw_vio_1]]]
  puts "Frame: $frames"

  # Freeze simulation
  set_property OUTPUT_VALUE 1 [get_hw_probes vio_sim_freeze]
  commit_hw_vio [get_hw_vios hw_vio_1]

  # Read trail map at (x=80, y=60)
  set addr [expr {60 * 160 + 80}]
  set_property OUTPUT_VALUE $addr [get_hw_probes vio_trail_addr]
  set_property OUTPUT_VALUE 1 [get_hw_probes vio_trail_read_en]
  commit_hw_vio [get_hw_vios hw_vio_1]
  after 100  ; # Wait for read
  set pixel [get_property INPUT_VALUE [get_hw_probes trail_data_b_out]]
  puts "Pixel at (80,60): $pixel"

  # Inject LFSR seed
  set_property OUTPUT_VALUE 0xDEADBEEF [get_hw_probes vio_seed_value]
  set_property OUTPUT_VALUE 1 [get_hw_probes vio_inject_seed]
  commit_hw_vio [get_hw_vios hw_vio_1]
  set_property OUTPUT_VALUE 0 [get_hw_probes vio_inject_seed]
  commit_hw_vio [get_hw_vios hw_vio_1]

JTAG-TO-AXI - MEMORY ACCESS
================================================================================

Configuration:
  - Protocol:       AXI4-Lite
  - Data Width:     32 bits
  - Address Width:  32 bits
  - Base Address:   0x00000000
  - Memory Size:    19,200 bytes (160×120 trail map)

Memory Map:
┌────────────────┬────────────┬─────────────────────────────────────────────┐
│ Address Range  │ Size       │ Description                                 │
├────────────────┼────────────┼─────────────────────────────────────────────┤
│ 0x0000-0x4AFF  │ 19,200 B   │ Trail map (160×120 pixels, 1 byte each)     │
│                │            │   Pixel[y][x] @ addr = y * 160 + x          │
│                │            │   Value: 0-255 (trail intensity)            │
├────────────────┼────────────┼─────────────────────────────────────────────┤
│ 0x4B00+        │ -          │ Reserved / Unmapped                         │
└────────────────┴────────────┴─────────────────────────────────────────────┘

Address Calculation:
  Linear address = y * WIDTH + x
  Where:
    x: 0-159 (column)
    y: 0-119 (row)
    WIDTH: 160

  Example: Pixel at (x=100, y=50)
    Address = 50 * 160 + 100 = 8,100 (0x1FA4)

Reverse (address to coordinates):
  x = address % 160
  y = address / 160

  Example: Address 8,100
    x = 8100 % 160 = 100
    y = 8100 / 160 = 50

TCL Commands:
  # Read single pixel at (x=80, y=60)
  set addr [expr {60 * 160 + 80}]
  create_hw_axi_txn read_px [get_hw_axis hw_axi_1] \\
    -address $addr -len 1 -type read
  run_hw_axi read_px
  set pixel [get_property DATA [get_hw_axi_txns read_px]]
  puts "Pixel: $pixel"

  # Read entire row (y=60)
  set start_addr [expr {60 * 160}]
  create_hw_axi_txn read_row [get_hw_axis hw_axi_1] \\
    -address $start_addr -len 160 -type read
  run_hw_axi read_row
  set row_data [get_property DATA [get_hw_axi_txns read_row]]

  # Write pixel at (x=50, y=40) with value 255
  set addr [expr {40 * 160 + 50}]
  create_hw_axi_txn write_px [get_hw_axis hw_axi_1] \\
    -address $addr -data 255 -type write
  run_hw_axi write_px

  # Dump entire memory to file
  create_hw_axi_txn dump_all [get_hw_axis hw_axi_1] \\
    -address 0x0000 -len 19200 -type read
  run_hw_axi dump_all
  set data [get_property DATA [get_hw_axi_txns dump_all]]
  set fp [open "trail_map_dump.bin" w]
  fconfigure $fp -translation binary
  puts -nonewline $fp $data
  close $fp

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "No debug cores found"
Solution:
  - Verify debug-enabled bitstream programmed
  - Check build used build_with_debug.tcl
  - Look for debug_hub in design

Problem: "ILA not triggering"
Solution:
  - Use immediate trigger mode for test
  - Check clock is running (VIO frame_count)
  - Verify trigger condition syntax
  - Increase trigger position

Problem: "VIO shows zeros"
Solution:
  - Verify mark_debug attributes in RTL
  - Check clock domain
  - Refresh VIO dashboard
  - Re-program device

Problem: "JTAG-to-AXI read fails"
Solution:
  - Verify address in range (0x0000-0x4AFF)
  - Check AXI BRAM controller instantiated
  - Try smaller read burst
  - Use single-byte transactions

Problem: "Timing violations with debug"
Solution:
  - Reduce ILA depth (8192 -> 4096)
  - Disable advanced triggering
  - Add input pipeline stages
  - Check critical path timing
