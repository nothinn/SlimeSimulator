TROUBLESHOOTING
================================================================================

Problem: Build fails
Solution: Check Vivado version, verify all source files present

Problem: Debug cores not found
Solution: Ensure debug bitstream programmed, check mark_debug attributes

Problem: ILA not triggering
Solution: Use immediate trigger, verify clock running

Problem: VIO shows zeros
Solution: Refresh dashboard, check clock domain

Problem: Memory access fails
Solution: Verify address range, try single-byte transactions
