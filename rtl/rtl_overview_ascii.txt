┌─ LFSR ────────────────────────────────────────────────────────────────────┐
│  Location: lfsr.sv:8                                                       │
│  Lines: 80 LOC                                                             │
│  Purpose: Generate deterministic pseudo-random numbers                     │
│  Type: 32-bit Maximal-Length Linear Feedback Shift Register                │
│  Polynomial: x^32 + x^31 + x^29 + x^1 + 1                                │
│  Width: 32 bits                                                            │
│  Period: 2^32 - 1 (4,294,967,295 states)                                 │
│  Resources: ~150 LUT, ~32 FF                                              │
│  Usage: Agent angle initialization, randomization                          │
└────────────────────────────────────────────────────────────────────────────┘

┌─ agent_processor ──────────────────────────────────────────────────────────┐
│  Location: agent_processor.sv:50                                            │
│  Lines: 350 LOC                                                            │
│  Purpose: Core simulation engine - 19-stage pipelined processor             │
│  Architecture: Continuous pipeline processing 1000 agents                   │
│                                                                             │
│  Pipeline Stages:                                                          │
│   Stages 1-3:   Forward sensor angle calculation + trig lookup            │
│   Stages 4-5:   Forward trail read from memory                            │
│   Stages 6-8:   Left sensor angle calculation + trig lookup               │
│   Stages 9-10:  Left trail read from memory                               │
│   Stages 11-13: Right sensor angle calculation + trig lookup              │
│   Stages 14-15: Right trail read from memory                              │
│   Stage 16:     Decision logic (compare F/L/R, select best direction)     │
│   Stage 17:     Angle rotation update (turn_speed)                        │
│   Stage 18:     Position calculation (move_speed)                         │
│   Stage 19:     Agent write + trail deposit                               │
│                                                                             │
│  Performance:                                                              │
│   - 1 agent per 19 clock cycles                                           │
│   - 1000 agents × 19 = 19,000 cycles per frame                            │
│   - @ 100 MHz: 5.26M agents/second throughput                             │
│   - @ 60 FPS: 19,000 cycles = 190 μs processing time                      │
│                                                                             │
│  Resources: ~2,500 LUT, ~800 FF                                           │
└────────────────────────────────────────────────────────────────────────────┘

┌─ trig_lut ────────────────────────────────────────────────────────────────┐
│  Location: trig_lut.sv:15                                                   │
│  Lines: 40 LOC                                                             │
│  Purpose: Sine and Cosine lookup table                                     │
│  Type: Dual ROM (sin + cos in parallel)                                   │
│  Entries: 1024 (10-bit address)                                           │
│  Format: Q12.12 fixed-point (signed)                                      │
│  Range: ±2047.9998 (12-bit int + 12-bit frac + 1-bit sign)               │
│  Access Time: 2 cycles (pipeline registered)                              │
│  Generated from: sin_lut.hex, cos_lut.hex                                │
│  Resources: ~600 LUT (ROM), ~50 FF                                        │
└────────────────────────────────────────────────────────────────────────────┘

┌─ fixed_point_mult ────────────────────────────────────────────────────────┐
│  Location: fixed_point_mult.sv:10                                          │
│  Lines: 50 LOC                                                             │
│  Purpose: Q12.12 fixed-point signed multiplication                         │
│  Formula: result = (a × b) >> 12  (with saturation)                       │
│  Input: Two Q12.12 signed numbers (25 bits each)                          │
│  Output: Q12.12 signed result (25 bits)                                   │
│  Intermediate: 50-bit product                                              │
│  Instantiated: 3 times in agent_processor                                  │
│  Resources: ~700 LUT (3×), ~200 FF (3×)                                   │
│  Used for: Position updates, angle calculations, sensor distance scaling   │
└────────────────────────────────────────────────────────────────────────────┘

┌─ trail_mem ───────────────────────────────────────────────────────────────┐

┌─────────────────────────────────────────────────────────────────────────────┐
│                            DATA FLOW EXAMPLE                                │
└─────────────────────────────────────────────────────────────────────────────┘

Single Agent Processing Cycle (19 clock cycles):

Clock→ Cycle 0 Cycle 1-3       Cycle 4-5     Cycle 6-8       Cycle 9-10
      ┌──────────────────────────────────────────────────────────────────
      │ Agent ID
      │ (10 bits)
      │    ↓
      │ [Stages 1-3]
      │ Forward angle calc + trig lookup
      │    ↓ (Q12.12 trig output)
      │ [Stages 4-5]
      │ Forward trail memory read
      │    ↓ (8-bit intensity: 0-255)
      │
      │                            [Stages 6-8]
      │                            Left angle calc + trig lookup
      │                               ↓
      │                            [Stages 9-10]
      │                            Left trail memory read
      │                               ↓
      │
      │                                           [Stages 11-13]
      │                                           Right angle calc + trig lookup
      │                                              ↓
      │                                           [Stages 14-15]
      │                                           Right trail memory read
      │                                              ↓
Cycle→ 11-16                                    Stage 16: Decision Logic
      │                                         IF (forward > left) AND (forward > right)
      │                                            → MOVE FORWARD
      │                                         ELSE IF (left > right)
      │                                            → TURN LEFT
      │                                         ELSE
      │                                            → TURN RIGHT
      │                                              ↓
      │                                         Stage 17: Angle Update
      │                                         new_angle = old_angle + turn
      │                                              ↓
      │                                         Stage 18: Position Calc
      │                                         new_x = x + cos(angle) * speed
      │                                         new_y = y + sin(angle) * speed
      │                                              ↓
      │                                         Stage 19: Memory Write
      │                                         agent_mem[agent_id] ← new_state
      │                                         trail_mem[new_pos] += deposit
      │
      └──────────────────────────────────────────────────────────────────

NEXT Agent (Agent 1) starts at Cycle 19, while Agent 0 completes at Cycle 18


┌─────────────────────────────────────────────────────────────────────────────┐
│                         FRAME EXECUTION TIMELINE                             │
└─────────────────────────────────────────────────────────────────────────────┘

Frame Duration: 16.67 ms (60 FPS)
Total Clock Cycles Available: 1,667,000 (@ 100 MHz)

Simulation Processing: 1,000 agents × 19 cycles = 19,000 cycles (1.14%)
  ├─ Agent 0:   Cycles 0-18
  ├─ Agent 1:   Cycles 19-37
  ├─ Agent 2:   Cycles 38-56
  ├─ ...
  └─ Agent 999: Cycles 18,981-18,999

VGA Display Refresh: 640 × 480 pixels = 307,200 cycles (18.4%)
  ├─ Blanking + sync: ~518,400 cycles (31.1%)
  │
  └─ Available Headroom: ~1,050,000 cycles (62.9%)
     (for future features: decay, multiple species, parameter updates, etc.)

Note: All timings run in parallel. Agent processing doesn't stall VGA updates.

INPUTS (Basys3 FPGA):

  sw[0]         (V17)  → Switch 0 (Pause)
  sw[1-15]      (...)  → Additional switches (reserved)

OUTPUTS (Basys3 FPGA):
  vga_r[3:0]    (B19, C19, A19, D19)  → Red channel
  vga_g[3:0]    (D18, E18, G18, D17)  → Green channel
  vga_b[3:0]    (E19, F19, F18, G19)  → Blue channel
  vga_hs        (N19)  → Horizontal sync
  vga_vs        (P19)  → Vertical sync
  led[15:0]     (...)  → LED status indicators


┌─────────────────────────────────────────────────────────────────────────────┐
│                        KEY PERFORMANCE METRICS                              │
└─────────────────────────────────────────────────────────────────────────────┘

Agent Throughput:
  Per Agent:      19 clock cycles
  @ 100 MHz:      100 MHz / 19 = 5.26M agents/second

Simulation Frame Rate:
  @ 60 FPS:       1000 agents per frame
                  1000 × 19 = 19,000 cycles per frame
                  19,000 / 1,667,000 = 1.14% utilization

Memory Bandwidth:
  Trail Reads:    3 reads per agent × 1000 agents = 3,000 reads/frame
  Trail Writes:   1 write per agent × 1000 agents = 1,000 writes/frame
  Agent Reads:    1 read per agent per cycle
  Agent Writes:   1 write per agent per cycle

Critical Path:
  Trail mem read → Comparison → Multiplier → Registered output
  Estimated delay: ~3 ns (well within 10 ns @ 100 MHz)
  Slack: ~7 ns (timing satisfied)
