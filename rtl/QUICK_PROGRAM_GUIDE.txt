FASTEST METHOD: Vivado Hardware Manager GUI
================================================================================

1. Connect Basys3 board via USB
2. Open Vivado 2025.2
3. Click: Flow Navigator -> PROGRAM AND DEBUG -> Open Hardware Manager
4. Click: "Open target" -> "Auto Connect"
5. Right-click on xc7a35t_0 -> "Program Device"
6. Browse to bitstream file (select one above)
7. Click "Program"
8. Wait ~10 seconds for programming
9. Design starts running immediately after programming

================================================================================

TROUBLESHOOTING
================================================================================

If programming fails:
  1. Check USB cable connection
  2. Verify Basys3 power (Power LED on)
  3. Check JTAG mode jumper (should be in JTAG position)
  4. Try different USB port
  5. Restart Vivado Hardware Manager

If display shows nothing:
  1. Check VGA cable connection
  2. Verify monitor is on correct input
  3. Try different monitor/cable
  4. Re-program the bitstream
  5. Press RESET button on Basys3

If display is garbled:
  1. Check timing (should see stable image)
  2. Verify bitstream programmed correctly
  3. Try VGA test pattern first (simpler design)
